# Инструкция для работы с Markdown

Markdown — это простой язык разметки, который позволяет форматировать
текст обычными символами с клавиатуры. Он создан для того, чтобы писать
быстро и читаемо: даже без «рендера» исходник остаётся понятным.
Ниже — базовый обзор по ключевым темам.

=====================================================================
## Выделение текста
=====================================================================

В Markdown есть несколько способов выделить важное:

- *Курсив*       — одна звёздочка или подчёркивание вокруг слова:
                   *текст*  или  _текст_
- **Жирный**     — две звёздочки или два подчёркивания:
                   **текст**  или  __текст__
- ***Жирный курсив*** — три звёздочки: ***текст***
- ~~Зачёркнутый~~ — две тильды: ~~текст~~
- `Моноширинный` — обратные кавычки: `код`
- > Цитата       — символ ">" в начале строки

Для заголовков используйте "#" в начале строки.
Один "#" — самый крупный заголовок, шесть "######" — самый мелкий.

    # Заголовок 1
    ## Заголовок 2
    ### Заголовок 3

=====================================================================
## Списки
=====================================================================

Markdown поддерживает маркированные и нумерованные списки.

Маркированный список — используйте "-", "*" или "+":

    - Пункт 1
    - Пункт 2
      - Вложенный пункт

Нумерованный список — используйте цифры с точкой:

    1. Первый
    2. Второй
       1. Вложенный

Важно: после маркера ставьте пробел.
Вложенность задаётся отступом (обычно 2–4 пробела).

=====================================================================
## Работа с изображениями
=====================================================================

Синтаксис похож на ссылки, но с восклицательным знаком в начале:

    ![Альтернативный текст](путь/к/картинке.jpg)

- ![ ... ]  — описание изображения (alt-текст), важно для доступности
- ( ... )   — путь к файлу или URL

Если картинка не загрузится, читатель увидит alt-текст.

=====================================================================
## Ссылки
=====================================================================

Обычная ссылка:

    [Текст ссылки](https://example.com)

Ссылка с подсказкой:

    [Текст](https://example.com "Подсказка при наведении")

Автоматическая ссылка:

    <https://example.com>

Ссылка-сноска (удобно, если один URL используется много раз):

    [Текст][1]

    [1]: https://example.com

## Работа с таблицами
=====================================================================

Таблицы создаются с помощью вертикальных черт "|" и дефисов "-".
Дефисы отделяют заголовок от тела:

    | Имя  | Возраст | Город           |
    |------|---------|-----------------|
    | Анна | 25      | Москва          |
    | Иван | 30      | Санкт-Петербург |

Выравнивание задаётся двоеточиями в разделителе:

    :---    — по левому краю
    :---:   — по центру
    ---:    — по правому краю

=====================================================================
## Цитаты
=====================================================================

Цитата начинается с символа ">":

    > Это цитата.
    > Она может быть многострочной.

Вложенные цитаты — несколько ">":

    > Первый уровень
    >> Второй уровень

Внутри цитаты можно использовать другие элементы Markdown:
списки, ссылки, выделение.

=====================================================================
## Заключение
=====================================================================

Markdown — это минималистичный, но мощный инструмент.
Основные правила запоминаются за 10–15 минут:

    #        — заголовки
    * и _    — выделение
    - , 1.   — списки
    ![]()    — изображения
    []()     — ссылки
    |        — таблицы
    >        — цитаты

Главное — практика. Начните с простого текста, постепенно добавляя
разметку. Markdown используется в GitHub, README-файлах, документации,
мессенджерах и блогах, поэтому навык пригодится почти везде.
